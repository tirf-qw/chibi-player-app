# Chibi Player — Spotify в летающей голове (Windows)

Прозрачное окно без рамки поверх всех окон, как Bongo Cat: видна только голова.
Наведи на неё, и рядом откроется настоящий Spotify (open.spotify.com): главная, рекомендации,
Daily Mix, поиск, лайки, автопродолжение. Убрал курсор, и окно спрячется, музыка играет дальше.
Движок системный, WebView2 (как в Edge), свой Chromium не вшит.

## Управление
- **Наведи на голову**: открывается Spotify. При первом запуске войди в аккаунт (лучше по почте и паролю,
  вход через Google/Facebook в таком окне может не открыться).
- **Клик по голове**: пауза / продолжить. Голова крутится, пока играет музыка.
- **Перетаскивание**: тяни голову мышью.
- **Правый клик по голове**: сменить картинку, вернуть стандартную, закрыть плеер.
- Ключи и настройки разработчика Spotify больше **не нужны**.

## Как получить .exe без установки Rust
1. Загрузи все файлы этой папки в репозиторий на GitHub (папки `dist`, `src-tauri`, `.github` и файлы в корне).
2. Вкладка **Actions** -> **Сборка Chibi Player (Windows)** -> **Run workflow**.
3. Через 5-10 минут открой завершённый запуск -> внизу **Artifacts** -> скачай `ChibiPlayer-windows` (внутри `chibi-player.exe`).

## Сборка у себя
Нужны Node.js, Rust (rustup.rs) и «Build Tools for Visual Studio» (C++):
`npm install` и `npx tauri build --no-bundle`. Файл: `src-tauri/target/release/chibi-player.exe`.
